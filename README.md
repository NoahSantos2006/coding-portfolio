# Noah Santos | Coding Portfolio

A static portfolio for six coding projects in machine learning, computer vision, and data.

[View the live portfolio](https://noahsantos-portfolio.pages.dev/)

## Preview and deploy

Open `site/index.html` in a browser to preview the site. It uses plain HTML, CSS, and JavaScript with no build step. Cloudflare Pages hosts the contents of `site/`.

## Repository contents

Git includes the production source and its published assets. The local design examples and other unlisted files are ignored. Add new public assets to the allowlist in `.gitignore` when you intend to publish them.

GoatCounter uses a public site code and runs only on the production hostname. Cloudflare deployment credentials are managed through Wrangler outside this repository.
